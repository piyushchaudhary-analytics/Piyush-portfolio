# Piyush Chaudhary — Portfolio

A responsive, single-page portfolio built with HTML, CSS and JavaScript. It is suitable for GitHub Pages.

## Before publishing — personalise these details
1. Replace `YOUR.EMAIL@example.com` with your professional email.
2. Replace `YOUR-LINKEDIN` and `YOUR-GITHUB` with your profile usernames/URLs.
3. Add the exact internship organisation, dates and responsibilities.
4. Add the hydraulic-lift project duration, your contribution, technical details and outcome.
5. Verify the exact titles and dates on each EY certificate; remove any certificate entry that does not match a certificate you hold.
6. Add project screenshots, GitHub repositories and measurable outcomes when available.
7. Review the skills section and keep only skills you can discuss confidently in an interview. Move beginner-level tools into “Currently learning”.

## Publish with GitHub Pages
1. Create a GitHub repository named `piyush-chaudhary-portfolio` (or any name you prefer).
2. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. Your public website URL will appear in the Pages section.

## Important
The site uses a few facts available from the conversation, but it deliberately leaves private contact details and unconfirmed internship specifics as placeholders. Verify every statement before sharing the portfolio with recruiters.
